# Weather Evidence Gallery

A public-facing gallery for carefully reviewed weather materials and supporting context.

## Publication safeguards

- Only display copies that have been specifically reviewed and approved for public release may be added.
- Keep original evidence, private working files, personal information, and unreviewed material out of this public repository.
- Do not copy content from the private `Master-File` repository into this repository.
- Clearly distinguish verified source information, calculations, supported interpretations, unverified claims, and unknowns.
- A gallery entry is not, by itself, proof of a cause or conclusion.

## Current status

The site shell is in place. The public catalog is intentionally empty until individual materials are reviewed and approved.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` deploys the repository root to GitHub Pages when Pages is configured to use GitHub Actions. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if it is not already selected.
